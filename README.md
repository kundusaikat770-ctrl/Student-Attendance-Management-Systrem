Student Attendance Management System
A simple Python-based Student Attendance Management System developed as a college project for managing student details and attendance through a terminal interface.
Features : 
Add student details
Add student details
    1. View all students
    2. Search students using roll number
    3. Take attendance for all students
    4. Mark attendance for an individual student
    5. Generate attendance reports
    6. Find students with attendance below 75%
    7. View overall class attendance summary
    8. Basic input validation
    9. Simple colour-coded terminal output
Technologies Used
    1. Python 3
    2. Command Line / Terminal
    3. Python Lists
    4. Functions and Conditional Statements
    5. Loops and Exception Handling
External libraries: None
How to Run
    1. Install Python 3.
    2. Download or clone this repository.
    3. Open the project folder in a terminal.
    4. Run : python student_attendance.py
If required use : python3 student_attendance.py
Select an option from the main menu and follow the instructions
Main menu : 
    1. Add Students
    2. View All Students
    3. Search Student
    4. Take Attendance
    5. Mark Individual Attendance
    6. Attendance Report
    7. Low Attendance Students
    8. Class Summary
    9. Exit
Attendance Calculation
Absent = Total Classes - Present Classes
Attendance % = (Present Classes / Total Classes) × 100
Students with attendance below 75% are displayed in the low-attendance section
