# Student Attendance Management System
It is a system based on Python which is intended for the management of student records and attendance in a terminal environment, and it was created as part of a college project.
## Key functionalities include:
- To enter the details of a new student.
Showing a list of all the registered students.
- Look for students using their roll number.
- Keep a record of all students' attendance at the same time.
- Recording the attendance of individual students.
- Generating attendance reports.
- Identify the students who have an attendance rate below 75%.
- Giving a summary of the whole class attendance.
- Include mechanisms for input validation.
Showing the output with colour in the terminal.
## The system utilizes:
- Python 3
- Terminal/Command Line interface
- Things such as Lists and Functions which are part of standard Python data structures.
- Including if-else statements and loops.
Use try-except statements for validating input.
None of the external libraries were used in the development of it.
## how to run the project:
Make sure that Python 3 is installed on your system.
2. Download the project files.
Go to the directory of the project in your terminal.
4. Carry out the command python student_attendance.py.
Alternatively, if the first command doesn't work then try running python3 student_attendance.py.
When the program is executed, a menu will appear and the users will be able to choose their options by typing in the relevant number.
## The main menu provides the following options:
1. Add Students
2. View All Students
3. Search Student
4. Take Attendance
5. Mark Individual Attendance
6. Attendance Report
7. Low Attendance Students
8. Class Summary
9. Exit
## Attendance is calculated using the following formulas:
Absent = Total Classes - Present Classes
Attendance % = (Present / Total) * 100
The students whose attendance drops below 75 per cent are included on the low attendance list.
