# Student Attendance Management System
## Problem Statement
Keeping track of student attendance by hand can take a lot of time. Might result in mistakes. A basic computer system can make the process much easier and more organized.
The Student Attendance Management System is a program written in Python that helps users keep student information, record attendance and see attendance reports.
## Objectives
1. Keep details about students.
2. Record attendance for students as Present or Absent.
3. Calculate attendance percentage automatically.
4. Look up. See records for each student.
5. Find students who have attendance than 75%.
6. Show a summary of the class attendance.
## Proposed Solution
The system uses a menu that runs in the terminal. Student details are kept in a Python list while the program is running. The user can add students, record attendance look up records and create reports using the menu options provided.
## Main Modules
### 1. Student Management
- Add students
- See students
- Find students
### 2. Attendance Management
- Record attendance for all students
- Record attendance for one student
### 3. Reports & Analytics
- Attendance report
- List of students with low attendance
- Summary of class attendance
## Scope
This project is meant to be a Python application for college students to show basic programming ideas like lists, functions, loops if statements, checking input and doing calculations.
## Limitation
Student and attendance details are kept in memory only. The current version does not use a database. Save data to a file. So when the program is closed all the data is lost.
## Expected Outcome
The system gives a way to manage student attendance find attendance percentages and spot students who need help with their attendance.
The Student Attendance Management System shows how basic Python skills can be used to solve a problem in college through a simple and easy to use terminal program.
